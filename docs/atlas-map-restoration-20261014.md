# Occupation Atlas IV — 立体地図とトップ復元（2026-10-14）

## ユーザーからの不具合証拠
公開トップのスクリーンショットで、右側のOGP画像に埋め込まれた見出しが枠で切れ、上から重ねた同じ職業名と衝突している。画像ギャラリー方式は職業記事のOGP資産を写真扱いしており、用途が間違っている。トップから全職業マップを撤去した前回変更も、サイト固有の最大の特徴を失わせた。

## 今回の設計
- トップは職業の世界への導入を短くし、職業マップを第一の操作面に配置する。OGP画像はヒーローのアートとして流用しない。
- 150の職業を一枚の地図に全て表示。業界は角度で区画化、編集上の知名度は半径で表現。従来の `layoutWorldMap` を再利用するので位置は安定。
- 立体感は扇形のレイヤー、同心円の地形表現、ノードの隆起と影、および視点角度の切替で構成。画面全体を回転させる3Dモデルではない。
- 全ての関係線を常時出さない。選択した職業に直接つながる上位6職業の線とノードだけを強調する。
- 地図の選択操作に加え、検索、一覧select、サイドの理由付きリンクを提供。ズームと立体/俯瞰を切り替え可能。
- 静的エクスポートと既存記事/URL/比較室/地図のタクソノミーを維持する。

## 技術選定
Next.js 16 / React 19 / SVG / CSS perspective。Three.jsはこのデータ数では不要なバンドル・描画負荷が増えるため導入しない。SVG座標系で描画と操作のヒット領域を共有し、以前のSVG画像とHTML透明ボタンの位置不整合を避ける。

## 品質ゲート
CIの `npm run lint` / `npm run build` / データ整合性 / SEO検査。Cloudflare Pagesのproductionでコミットとalias確認。PC/モバイル実ブラウザの画像・タップ/キーボード・地図の操作確認は別途実施し、未実施の場合は未検証と報告する。
