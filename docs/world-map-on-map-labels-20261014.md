# 全体地図の点を職業名に戻す（2026-10-14）

## 直接の問題
ユーザーが共有した地図では光る点と線だけが強調され、どの職業へ線がつながっているのか画面内で判読できなかった。前回は別の「関係を読む」ビューを追加したが、ユーザーの求める修正は**元の150職業の全体地図上で点の意味が読めること**だった。

## 設計
- 入口を再び「全体地図」にする。ただし元の匿名ノード地図に戻すのではない。全150点の配置を維持し、選択仕事＋直接つながる最大6職業の**実在する職業名、番号、分類と共通点**を地図に常時表示する。
- 位置をそのまま文字に変えると重なるため、6枚のラベルを左右に各3つの衝突しない場所へ配置。各職業の実座標から接続ラベルへリーダー線を引く。最小距離の配置を6枠の小さな割り当て計算で求める。
- ノード近くの番号とラベル上の番号を対応させる。背景の約150ノードは暗くするがクリック可能なまま残し、選択するとラベルがすぐ更新される。
- 選択中の仕事は画面内の上部に明示。関係をたどると探索履歴は既存機能で記録される。
- SVGの表示座標はズーム時に別スケールで計算し、拡大した際にラベルの画面サイズが変化しないようにする。
- 以前実装した「関係を読む」「業界地図」も維持。スマホでは地図をスクロールしながら、職業の意味を確認できる。
- 長い共通点はラベル内で省略するが、スクリーンリーダー向けのaria-labelは元データ全文。右側の説明にも全文が残る。

## 検証
型チェック、ESLint、データ、SEO、静的出力のCI結果を確認。Cloudflare Pagesで対象コミットと独自ドメインを確認する。実画面のスクリーンショットが未取得の場合はその制約を明記する。
