# しごと図鑑 — 体験設計 Edition II
2026-10-14

## 既存コンテンツの特性
150職業の固有ページ、各職業の意外な事実・概要・独自OG画像、7軸タグ、関係グラフ。地図は探索の途中経路に優れているが、巨大な図を最初から理解する必要があり、名前検索やカテゴリ探索の即時性に欠ける。カード一覧は1件ずつ閲覧する負荷が高い。

## 判断
「知っている仕事から探索」「知らない仕事に偶然出会う」「一つの職業を深く読む」という3つの入り口を、ファーストビューに具体的な画像・職業名・行為として露出する。抽象的な軌道図を主役から降ろし、実在する収録画像を主役にする。地図は既存の重要なナビゲーションとして残す。
職業一覧は分野＋既知度／珍度＋テキストで即時フィルターできる索引に置き換える。統計的な稀少度とは解釈させない。
個別記事は「その仕事と他の仕事を比べる」行為を冒頭に明示し、既存本文／資料／ネットワーク／SEOメタデータを維持する。

## 選定技術
既存 Next.js Server Componentsと、索引のReact小コンポーネント。既存OGアセットを再利用。CSS Gridによる可変密度の誌面。追加ライブラリなし。Three.jsやGSAPは分類・比較・検索の理解を増やさずコストが大きいので不採用。

## 検証
npm run verify、スマートフォンとデスクトップのレイアウト、検索・フィルター、公開画像、職業詳細への遷移、地図と比較室への遷移、公開本番の確認。実行できない項目は未検証として報告する。
