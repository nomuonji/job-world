# 職業比較室の設計判断

## 現状と目的
既存の仕事地図は業界・知名度と6本の関係線を表示する。興味を引いた2職業を、就業条件の推測ではなく収録済みの7軸タグに基づいて理解する補完体験を提供する。

## 情報設計
地図（意外な仕事を見つける）→比較室（二つの特徴を読み解く）→職業詳細（本文・根拠を確かめる）。各職業の既存URL・本文・SEO構造は変えない。

## 技術
Next.js Server Componentで職業・分類データを取得、Client Componentには比較に必要なslug/name/summary/surprise/tagsだけを渡す。CSS Gridによる3列比較。D3/Three.js/GSAPを導入しない理由は、データが分類タグの集合で、装飾的な3Dやアニメーションより文字による差分表示が正確で高速だから。操作はselect、検索、軸フィルター、交換ボタン。JSなしでの比較は未対応。

## 正確性
共通タグは編集分類の重なりであり、転職適性・賃金・就業人口統計ではない。タグがないことから否定的事実を導かない。記事の出典は既存詳細ページで維持。

## 検証項目
2職業を別々に選択、同一選択を抑止、左右交換、検索結果からの置換、軸フィルタ、キーボード操作、375px/1440pxの折り返し、色・文字の可読性、prefers-reduced-motion、buildと本番URLの到達性を確認する。
