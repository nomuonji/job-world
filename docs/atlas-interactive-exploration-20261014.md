# 仕事マップ Atlas IV — 見る地図から「辿る地図」へ

## 根拠
2026-10-14の公開画面スクリーンショットでは、全150職業の点と3Dの円盤が表示できている。以前の「地図を撤去する」失敗からは回復した。一方で、次の課題を観察した。
- 円周の小さい業界ラベルが上部で重なり、業界境界が分かりにくい。
- 選択された職業名が選択ノードのそばに大きく現れ、別の点や線を覆う。
- 点・線の色がほぼ同じで、関連理由を地図上だけでは判断できない。
- 選択して次の職業へ進んでも「どこからどこへ来たのか」が残らない。
- 狭い画面では選択ノードが横スクロール領域の画面外に残りうる。

## 解決する読者の行為
1. **世界を俯瞰する**：150職業の分布を維持。業界名は幅に余裕のあるセクターだけSVGに表示し、小さいセクターは水平スクロール可能な業界索引から選択できる。
2. **違いを見つける**：全体／この業界／つながり、3つのレンズを切り替える。選択業界を少し浮かび上がらせ、無関係な点を減光する。選択ノード名は常時表示の詳細欄で読み、地図上の大きな重複ラベルを排除。
3. **次の仕事に旅する**：関係分類で色分けした線を辿る。確定済みの関連エッジの選択だけ足跡として残し、黄色い破線で位置を連ねる。検索／業界ジャンプは新しい起点にするので架空のキャリア経路を作らない。
4. **見知らぬ隣へ進む**：現在の職業の実際の隣人から、異業界・低知名度を優先する候補へ1クリックで移る。実測の適性や転職可能性の推薦ではない。
5. **操作可能である**：業界セクターはキーボード選択可能。スマートフォンで現在地へ自動横スクロール（reduced-motion対応）。

## 表現と実装
Reactで地図選択、探索経路、表示レンズを同期。従来の `layoutWorldMap` の位置／方角／知名度セマンティクスを保持。SVG内で地形、点、線、経路を描き、CSSで色／奥行き／減光を実装。既存のNext.js、追加依存なし。SEOと職業記事本文を変更しない。

## チェック
- CI: データ整合性、Lint、SEO、静的出力、画像生成のドリフト
- 表示: 1440px / 1180px / 390px で領域ラベル、レンズ、足跡、スクロール、文字の重なりを目視
- 操作: 地図でノードを選択、業界ジャンプ、サイドの隣人クリック、1クリック発見、戻る、検索、ズーム、立体／俯瞰、キーボード、reduced motion
- 本番: Cloudflare Pagesの最新mainコミットと独自ドメインへのエイリアスを検証する。CIだけでは実画面の見え方を保証しない
