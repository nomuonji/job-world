# 仕事マップ「何をしているか分からない」への修正（2026-10-14）

## 直接観察した問題
選択ノードから6本の線が離れた点に伸びているが、点に職業名が書かれていないため、「どこに線が届いているか」は分かっても「何の仕事同士が、何を共有しているのか」は分からない。薄い150点は視覚的な負荷になっており、3D・色の強調で解決できない。ユーザー提供のスクリーンショットが根拠。

## 操作体験の変更
- **最初に読める図**: 入口は「関係を読む」。中央に選択した職業名、その周囲に最大6件の実際の関連職業名とそれぞれのタグ由来の共通理由を直接表示。つながり線はカードに接続し、カード自体が職業を選び直す操作ボタン。
- **全体図は撤去しない**: 既存の150職業・業界・知名度を表す立体的な世界図は「全体地図」に残し、「業界地図」も切替可能。俯瞰と関係理解を異なるビューに分離する。
- **コンテキストを保つ**: 右側の職業説明と探索履歴は選択に連動。経路は実際の図鑑グラフの辺をたどった場合のみ連結。
- **可読性**: 色だけに依存せず、職業名と共有理由を明記。長い職業名は折り返す。スマホでは中央カード＋2列の関係カードへ変形し、線を無理に引かない。
- **計算の根拠**: 既存の graph edges（slug、dominantFacet、sharedLabelJa、reasonJa）のみ利用。性格・適職・収入等の根拠なき判断はしない。

## 品質確認
CIのデータ整合性、Lint、Next.js静的ビルド、SEOゲートを必須とし、成功したときだけマージ。Cloudflare PagesでマージSHAの本番配信完了を確認。実ブラウザのPC/スマホの目視確認を実施できなければ、未確認と明示する。
